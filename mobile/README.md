# Artemisa: app

Expo + Expo Router con React Native Reusables (NativeWind). Detalle en
`docs/07-APP.md` y `docs/09-DISENO.md`.

```bash
npm install
cp .env.example .env    # valores del laboratorio; nunca se commitea
npm run typecheck
npm run lint
npm test
```

La app usa módulos nativos: corre con un build de desarrollo, no en Expo Go
(`docs/07-APP.md`, Build de desarrollo).
